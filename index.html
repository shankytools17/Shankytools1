003 / THE RULES

Why this matters

Every tool listed here is open-source and has a legitimate security purpose: finding weaknesses before someone else does. That purpose depends entirely on permission. Using these against a system you don't own or don't have written authorization to test is a criminal offense, not a gray area. We link to official sources, we credit original authors, and we don't host modified binaries.
